# Praveen Kumar Pasupuleti — Portfolio

A responsive portfolio website built with HTML, CSS and JavaScript.

## Run in VS Code
1. Extract the ZIP folder.
2. Open the `praveen_portfolio` folder in VS Code.
3. Open `index.html` in your browser, or install the **Live Server** extension and choose **Open with Live Server**.

## Before publishing
- Your email and LinkedIn profile are already added. Verify both links before publishing.
- Add your phone number to the contact section only if you want it publicly visible.
- Add your PDF resume to `assets/Praveen_Kumar_Pasupuleti_Resume.pdf`.
- Verify employment dates, designation, education title and every skill/claim.
- The three project cards are clearly marked as planned case studies. Build them before describing them as completed projects.
- Never add confidential employer/client data.

## Publish with GitHub Pages
Upload the files and folders in this project to the root of your GitHub repository (the folder containing the site's `index.html`). Commit the changes and ensure GitHub Pages is configured to deploy from the correct branch and folder.
